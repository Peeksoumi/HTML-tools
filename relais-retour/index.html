    Fonctionnement et sources

    Fonctionnement

    • Recherche : rien n'est envoyé tant que la position de départ n'est pas connue ; ensuite chaque source activée est interrogée en parallèle autour de cette position (rayon au choix).
    • Fusion : les points d'un même réseau et type à moins de 40 m sont regroupés ; l'API relais, si elle est activée, l'emporte et est complétée par OpenStreetMap.
    • API relais : toute API (Mondial Relay, DPD, Sendcloud…) se branche via un petit serveur qui garde la clé et renvoie le format du README ; l'URL se règle dans « Sources de données ».
    • Réseau : déduit des étiquettes OSM (marque, opérateur, nom). Type : locker = amenity=parcel_locker ; bureau de poste = amenity=post_office ; sinon point relais en commerce.
    • Mise à jour : la base OSM est modifiée en continu ; la page recharge les données à chaque nouvelle zone et garde 24 h de cache dans ton navigateur (bouton « Actualiser » pour forcer).
    • Horaires : lus dans la balise opening_hours d'OSM et comparés à l'heure de Paris ; le bouton « Horaires » ouvre la fiche Google Maps du lieu pour recouper.
    • Confidentialité : ta position et ta recherche sont envoyées aux services listés ci-dessous, et à l'API relais si tu l'actives ; rien n'est envoyé à un serveur du site sans cela.

    Sources de données

    • OpenStreetMap via Overpass API : emplacement, réseau, adresse, horaires des points (ODbL, © contributeurs OpenStreetMap).
    • API relais (facultative) : points d'un serveur que tu indiques (ex. Mondial Relay officiel) ; conditions de la source concernée.
    • Nominatim : transformation d'une ville ou adresse en coordonnées.
    • Leaflet + tuiles OpenStreetMap : affichage de la carte (chargé depuis unpkg.com).
    • Google Maps (liens uniquement) : itinéraire et fiche du lieu, ouverts sur ton action ; aucune clé ni donnée Google n'est lue par la page.

    Limites

    • Mondial Relay ne publie pas la liste de son réseau (son API répond à une recherche à la fois, avec identifiants client) : seuls les points saisis dans OSM apparaissent, donc la liste est incomplète.
    • Les tailles de colis acceptées, la disponibilité d'un locker et les fermetures exceptionnelles ne sont pas connues ; vérifie sur ton bordereau ou la fiche Google Maps.
    • Horaires OSM saisis par des bénévoles : parfois absents ou périmés. Jours fériés et vacances (PH, SH) ignorés ; heure de Paris supposée.
