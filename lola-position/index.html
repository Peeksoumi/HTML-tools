Fonctionnement et sources

Fonctionnement

  • Lecture : la page interroge toutes les 5 s le relais AIS du même site (à défaut, sa copie publique GitHub) et affiche sa dernière position ; le relais cherche d'abord dans aisstream, puis AISVesselTracker, puis Shiptrail, si aisstream est muet depuis 20 s en mouvement ou 75 s à quai. L'âge se calcule à partir de l'heure AIS de la position.
  • Temps réel : entre deux relevés, la position est estimée en ligne droite d'après la vitesse et le cap (60 s au plus), puis lissée à l'arrivée du relevé suivant. Point plein = relevé, anneau = estimation.
  • Calcul : tout se fait dans le navigateur ; la page ne fait que lire ces positions et n'y envoie rien.

Sources de données

  • aisstream.io (1re source) : flux AIS temps réel de récepteurs de bénévoles (gratuit sur clé). Il refuse les navigateurs : la clé est un secret du VPS, dont le relais (bac-lola/relais) garde la connexion websocket pour le MMSI 227158520.
  • AISVesselTracker (2e) puis Shiptrail (3e) : pages / API publiques, lues par le relais seulement si aisstream est muet depuis 20 s en mouvement ou 75 s à quai.
  • Tracé du chenal : GTFS officiel « Bacs de Loire en Loire-Atlantique » (aller) ; le retour est son symétrique par rapport à l'axe nord-sud.

Limites

  • Sans relais sur le site (ex. GitHub Pages), la copie GitHub (raw.githubusercontent.com) peut avoir plusieurs minutes de retard.
  • Rien ne s'affiche tant que le relais n'a reçu aucune position. Les secours rafraîchissent environ toutes les 30 à 80 s : les positions sont plus espacées si aisstream ne capte pas l'estuaire de la Loire.
  • À quai, un bac n'émet qu'un relevé toutes les 3 à 5 min ; la page ne peut pas être plus fraîche que la source.
  • L'estimation est rectiligne : fausse dans les virages et à l'accostage. L'âge se calcule avec l'horloge de l'appareil.
